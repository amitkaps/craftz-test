# craftz-test

A package with a static site, started by craftz new to test the release cycle.

## Install

```sh
pnpm add @amitkaps/craftz-test
```

It needs Node 26 or newer, the Node it's built and tested on.

Read [the docs](docs/README.md) for its design, plan and lessons. It follows [craftz's rules](https://craftz.amitkaps.com/docs/rules.md) for how it builds, checks, releases and deploys.
